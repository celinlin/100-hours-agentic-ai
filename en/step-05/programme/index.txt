<li>The host launches the agent and opens one client per server</li>
<li>The client asks the server for the list of its tools</li>

<li>The model chooses, the client passes the call on</li>
<li>The server executes and sends back the result</li>
</ol><p><em>The server never sees the model. <section class="part-section" data-part="corrige"><header class="part"><span class="part__mark" aria-hidden="true">A</span><div class="part__titles"><p class="part__kicker">To read after the final test</p><h2 id="corrige" tabindex="-1">The answer key</h2></div></header><p>Your answer is right if it says the same thing in your own words.</p><div class="answers-wrap"><ol class="answers" start="1"><li class="answers__item"><span class="answers__n" aria-hidden="true">1</span><div><p class="answers__q">What is MCP?</p><p>An open standard: for plugging tools and data into an AI application, in a single way.</p></div></li><li class="answers__item"><span class="answers__n" aria-hidden="true">2</span><div><p class="answers__q">Host, client, server?</p><p>The host runs the agent and opens one client per server.

<li>Your code sends a method, an address and your token</li>
<li>Google checks the token: without it, response 401</li>
<li>It looks up the events for the requested day</li>
<li>It returns a status code and a JSON body</li>
<li>Your code extracts from it the text that goes to the model</li>
</ol><p><em>The model never sees the token. <li>
<p><strong>Read a raw response.</strong> With <code>requests</code>, call <a href="https://httpbin.org/get" target="_blank" rel="noopener noreferrer" class="ext" data-host="httpbin.org">httpbin.org/get<span class="sr-only"> (opens in a new tab)</span></a>, then <a href="https://httpbin.org/status/404" target="_blank" rel="noopener noreferrer" class="ext" data-host="httpbin.org">httpbin.org/status/404<span class="sr-only"> (opens in a new tab)</span></a>. </blockquote>

</blockquote>
</li>
</ol></div><p><strong>End of session 1.</strong> Reread your twelve lines and circle the one that surprised you most. You'll use it in the teach-back.</p></section>
